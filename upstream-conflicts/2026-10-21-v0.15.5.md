# Conflict review: upstream v0.15.0 through v0.15.5

2026-10-21. Draft for maintainer decisions, not a merged implementation. The attempted merge of upstream [`cede6ea4`](https://github.com/craft-ai-agents/craft-agents-oss/commit/cede6ea49e0c4a42933ed0f1bc129db698fc581f) into fork [`23eb6763`](https://github.com/Swagatar-LLC/vorno/commit/23eb676349aba917b56e09c38dd91197b140a3a8) produced **79 unresolved paths**. The merge was aborted; this branch contains only this review document. Its base is the already-landed upstream `332533f3` (v0.14.1). Do not merge this review PR as the sync.

## Release scope and impact

- v0.15.0: UI redesign, new models and Cloudflare AI Gateway, Claude artifact publication for Pages, live/stop background tasks and background shell actions. SDK 0.3.280 to 0.3.302 by v0.15.5; Pi 0.87.1 to 1.1.0.
- v0.15.1 through v0.15.5: see pinned [commit range](https://github.com/craft-ai-agents/craft-agents-oss/compare/332533f3...cede6ea4). Review commits individually before implementation; this document does not assert their behavior without validation.
- Roadmap: upstream changes `packages/shared/src/protocol/{types,channels,dto,events,routing,index,git-repos,pr-watch,message-limits}.ts`; `dto.ts` is conflicted. Audit new channels, DTO optionality, peers and routing against [compatibility commitments](../roadmap/upstream/compatibility.md) and [ADR-0001](../roadmap/decisions/0001-fork-relationship-with-upstream.md)/[ADR-0012](../roadmap/decisions/0012-additive-vorno-protocol-namespace.md). Agent options and source/permission code change, and CLI commands change. DIR-01 Canvas and DIR-03 Observatory consumers may need updates to events and UI. Pages publication must honor [ADR-0033](../roadmap/decisions/0033-pages-as-a-secure-opt-in-vorno-capability.md) and the free-plan constraint; do not silently enable a new sharing path. [ADR-0034](../roadmap/decisions/0034-decision-settings-follow-the-executing-host.md) governs decision/permission integration.
- SDK bump triggers the private LEARNING-008 non-interactive subagent-launch and nesting-cap audit. Keep `delete env.CLAUDECODE` and the five-level depth pin. Review upstream configuration, aliases, and Pi failure semantics before resolving the agent cluster.

## Decisions needed

1. Approve how the new Pages-to-Claude artifact action interacts with Vorno's default-off Pages gate, publication allowlist and source-action grants; do not take the upstream implementation unchanged.
2. Decide how much of upstream's visual redesign should replace the fork's navigation, tasks, permissions, and Pages controls. Identify any intentional fork UI divergence before resolving the renderer cluster.
3. Approve the SDK and Pi dependency upgrade only after launch-semantics and packaging audits. Version stamps remain Vorno-owned per ADR-0010.
4. Review protocol changes and all host/client consumers for optionality and routing. Publish a compatibility audit in the implementation PR.
5. Assign reviewers for browser ownership, session/steer durability, decision administration and CLI behavior. Do not run validations or claim a completed sync on this review-only branch.
