# Vorno User Guide

Most product documentation tells you what the buttons do. This section is about something different: **how to get real work done with Vorno, reliably.**

Vorno gives you a team of AI agents, not just a chat box. Working well with a team is a skill — knowing what to delegate, how to describe an outcome, when to check in, and when to get out of the way. These guides teach that skill.

## Guides

| Guide | What it teaches |
|-------|----------------|
| [Working with Projects and Big Tasks](working-with-projects-and-big-tasks.md) | The core mental model: how Vorno organizes work at different sizes, how to break up big jobs, and how to direct traffic among your agents. Includes a Technical Architecture appendix for advanced users. |
| [Artifact Roots and Storage](artifact-roots-and-storage.md) | What an artifact root is, how to add a local-folder root, and how to read the storage panel — kind, capabilities, and health. Advanced; behind the Artifacts feature flag. |

More guides are planned for this section — it's an area we invest in deliberately. If something here is confusing or missing, [open an issue](https://github.com/Swagatar-LLC/craft-agents-oss/issues).
